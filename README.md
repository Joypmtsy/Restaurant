## วิธีเปิดแอป

1. ติดตั้ง Node.js 24 และ npm
2. แตกไฟล์งาน แล้วเปิด Terminal ในโฟลเดอร์ Restaurant ที่มีไฟล์ package.json
3. ติดตั้งแพ็กเกจด้วยคำสั่งนี้

```bash
npm install
```

4. เปิดแอปด้วยคำสั่งนี้

```bash
npx expo start --clear
```

5. สแกน QR ด้วย Expo Go ที่รองรับ SDK 57 หรือกด i เพื่อเปิด iOS Simulator หรือกด a เพื่อเปิด Android Emulator โดยต้องติดตั้ง Simulator หรือ Emulator ไว้ก่อน
6. เลือกบทบาทที่หน้าแรกเพื่อเริ่มใช้งาน

ครั้งแรกที่เปิดแอป ระบบจะสร้างฐานข้อมูล พร้อมโต๊ะ 15 โต๊ะ หมวดอาหาร 4 หมวด และเมนู 25 รายการ

## วิธีใช้งาน

- ลูกค้าเลือกโต๊ะ เลือกอาหาร ใส่ตะกร้า และส่งออเดอร์ สามารถสั่งเพิ่มได้หลายรอบ
- ครัวดูออเดอร์และเปลี่ยนสถานะเป็น รอทำ กำลังทำ และเสิร์ฟแล้ว
- ผู้ดูแลแก้ราคา เปิดหรือปิดการขายเมนู ย้ายโต๊ะ รับชำระ และปิดบิล
- ผู้ดูแลดูยอดขาย ประวัติบิล และรายงานได้
- หากต้องการล้างรายการขาย ให้เปิดหน้าล้างข้อมูล กดปุ่ม Reset แล้วกดยืนยัน โต๊ะ เมนู และราคาจะยังอยู่

อาหารในตะกร้าที่ยังไม่ส่งจะหายเมื่อปิดแอป ข้อมูลที่ส่งแล้วจะเก็บใน SQLite

## ไฟล์หลัก

- App.js เป็นส่วนเลือกหน้า ย้อนกลับ และเชื่อมฐานข้อมูล
- src/screens เป็นหน้าจอของแอป
- src/components เป็นส่วนหน้าจอที่ใช้ร่วมกัน
- src/db เป็นส่วนทำงานกับฐานข้อมูล
- src/styles เป็นสีและรูปแบบหน้าจอ
- src/context/CartContext.js เป็นส่วนเก็บตะกร้า
- schema.sql เป็นคำสั่งสร้างตาราง ดัชนี และข้อมูลตั้งต้น สามารถรันใน SQLite ได้

## ไลบรารีที่เพิ่มจากตัวอย่างเรียน

- expo-linking และ expo-constants เป็นแพ็กเกจของ Expo ที่ติดตั้งไว้
- expo-asset ใช้จัดการไฟล์ของแอป
- react-native-reanimated และ react-native-worklets ใช้รองรับการแสดงผลของแพ็กเกจ
- react-dom และ react-native-web เป็นแพ็กเกจสำหรับเว็บ แต่โครงการนี้เน้นมือถือ

expo-sqlite ใช้เก็บข้อมูล และมีอยู่ในตัวอย่างที่เรียนแล้ว

## งานที่ทำแล้วและข้อจำกัด

ทำหน้าลูกค้า ครัว และผู้ดูแลแล้ว มีการสั่งหลายรอบ ดูสถานะ รวมบิล ย้ายโต๊ะ แก้ราคา รับชำระ ประวัติบิล รายงาน และล้างรายการขาย

เมื่อแก้ราคา อาหารที่สั่งไปแล้วจะใช้ราคาเดิม เพราะเก็บราคาไว้ตอนส่งออเดอร์

ราคาที่เก็บเป็นจำนวนเต็มหน่วยบาทตามที่กลุ่มเลือก ซึ่งต่างจากหน่วยสตางค์ในโจทย์เดิม ไม่มีส่วนค้นหาเมนู

ยังไม่มีการตั้งราคาล่วงหน้า การชำระ QR เป็นการบันทึกวิธีชำระ ยังไม่ได้เชื่อมกับธนาคาร ข้อมูลของแต่ละเครื่องไม่ได้เชื่อมกัน

ตรวจ lint ผ่านแล้ว เคยตรวจการเปิดบน iOS และการสร้าง bundle ของ Android แต่ยังต้องลองใช้งานทุกหน้าบนมือถือก่อนส่ง

ตรวจโค้ดได้ด้วยคำสั่งนี้

```bash
npm run lint
```
