# HONEY RESTAURANT - แอปสั่งอาหารในร้าน

โปรเจกต์ React Native + Expo สำหรับงานกลุ่มวิชา 01418342 ใช้ SQLite เก็บข้อมูลในเครื่อง มีส่วนลูกค้า ครัว และผู้ดูแลร้าน

## ตอนนี้ทำอะไรได้

- เลือกโต๊ะ 1-15 และดูว่าโต๊ะไหนมีบิลเปิดอยู่
- ดูเมนู 4 หมวด รวม 25 รายการ และเลือกอาหารลงตะกร้า
- เพิ่มหรือลดจำนวน ใส่หมายเหตุ ส่งเข้าครัว และสั่งเพิ่มหลายรอบในบิลเดียวกัน
- ดูสถานะอาหารและยอดรวมของโต๊ะ ครัวเปลี่ยนสถานะรอทำ กำลังทำ และเสิร์ฟแล้วได้
- ผู้ดูแลเปิดหรือปิดขายเมนู เปลี่ยนราคา ย้ายโต๊ะ รับชำระ และปิดบิลได้
- ดูประวัติบิล รายงานยอดขาย และล้างรายการขายโดยเก็บโต๊ะ เมนู และราคาไว้
- เก็บราคาตอนสั่งไว้ในรายการอาหาร บิลเก่าจึงยังใช้ราคาเดิมเมื่อร้านเปลี่ยนราคา

ข้อมูลที่ส่งแล้วเก็บใน SQLite และยังอยู่เมื่อปิดแอป ส่วนอาหารในตะกร้าที่ยังไม่ส่งเก็บในหน่วยความจำและหายเมื่อปิดแอป

## วิธีติดตั้งและรัน

1. แตกไฟล์โปรเจกต์ แล้วเปิด Terminal ในโฟลเดอร์ Restaurant
2. ติดตั้ง Node.js 24 และ npm หากยังไม่มี
3. ติดตั้งไลบรารีของโปรเจกต์

```bash
npm install
```

4. เปิดแอป

```bash
npx expo start --clear
```

5. เปิด Expo Go ที่รองรับ SDK 57 แล้วสแกน QR หรือกด i เพื่อเปิด iOS Simulator หรือ a เพื่อเปิด Android Emulator หากติดตั้งไว้
6. เลือกลูกค้า ครัว หรือผู้ดูแลร้านที่หน้าแรก เพื่อเริ่มใช้งาน

ครั้งแรกที่เปิดแอป ระบบสร้างตารางและใส่ข้อมูลตั้งต้นให้ ไม่ต้องสร้างฐานข้อมูลเอง

## โครงสร้างไฟล์

- `App.js` เลือกหน้าที่แสดง จัดการย้อนกลับ และเชื่อมส่วนกลาง
- `src/screens/` เก็บหน้าลูกค้า ครัว และผู้ดูแลร้าน
- `src/components/` เก็บปุ่ม กรอบข้อมูล และส่วนหน้าจอที่ใช้ซ้ำ
- `src/styles/` เก็บสีและรูปแบบหน้าจอ
- `src/db/` เก็บคำสั่งอ่านและเขียน SQLite รวมถึงข้อมูลตั้งต้น
- `src/context/` เก็บตะกร้าและข้อมูลสำหรับเปลี่ยนหน้า
- `src/hooks/` ช่วยโหลดข้อมูลและจัดการการทำรายการ
- `src/utils/` จัดรูปแบบเงิน วันที่ และสถานะ
- `schema.sql` รวมคำสั่งสร้างตาราง ดัชนี และข้อมูลตั้งต้น

## ไลบรารีที่เพิ่มจากตัวอย่างเรียน

- `expo-asset` จัดการไฟล์ภาพของแอป
- `expo-linking`, `expo-constants`, `react-native-reanimated` และ `react-native-worklets` ติดตั้งไว้จากการตั้งค่าระบบเดิม ปัจจุบันไม่ได้เรียกใช้โดยตรงในโค้ดแอป
- `react-dom` และ `react-native-web` รองรับเว็บ แต่โปรเจกต์นี้เน้นมือถือ

ส่วน `expo-sqlite` ใช้เก็บข้อมูล, `react-native-safe-area-context` จัดพื้นที่ให้พ้นขอบหน้าจอ และ `expo-status-bar` จัดแถบสถานะ เป็นไลบรารีที่มีในตัวอย่างที่เรียนแล้ว เช่นเดียวกับ `react-native-screens` ที่ยังติดตั้งไว้

## สิ่งที่ยังไม่ได้ทำและข้อจำกัด

- ยังไม่ได้เชื่อมข้อมูลระหว่างหลายเครื่อง แต่ละเครื่องใช้ฐานข้อมูลของตัวเอง
- ยังไม่มีหน้าตั้งราคาเมนูล่วงหน้า
- QR เป็นการบันทึกวิธีชำระ ยังไม่ได้เชื่อมธนาคาร
- ใช้ราคาจำนวนเต็มหน่วยบาท ซึ่งต่างจากหน่วยสตางค์ในโจทย์เดิม และไม่มีช่องค้นหาเมนู
- ตรวจ lint และสร้าง bundle iOS/Android ผ่านแล้ว แต่ยังต้องทดสอบการใช้งานบนอุปกรณ์ Android ก่อนส่ง

ก่อนส่งให้เติมหมายเลขกลุ่มและลิงก์ YouTube แล้วนำเนื้อหานี้ไปจัดเป็น `README.docx` ตามคำสั่งอาจารย์ พร้อมส่ง ZIP, `schema.sql`, รายงาน PDF, คลิป และแบบประเมินเพื่อน โดย ZIP ไม่รวม `node_modules` และเก็บ `.git` ไว้
