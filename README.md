# Restaurant Order — 01418342

แอปสั่งอาหารในร้านด้วย Expo SDK 57, React Native และ expo-sqlite ลูกค้า ครัว และผู้ดูแลใช้ฐานข้อมูลเดียวกันในเครื่อง ตามโจทย์ ไม่ต้องมีเซิร์ฟเวอร์หรืออินเทอร์เน็ตสำหรับข้อมูลอาหารและบิล

## ติดตั้งและรัน

แนะนำ Node.js 24 และ npm

```bash
npm install
npx expo start --clear
```

กด `i` เพื่อเปิด iOS Simulator หรือ `a` เพื่อเปิด Android Emulator หรือสแกน QR ด้วย Expo Go ที่รองรับ SDK 57 ใช้ `npm run ios -- --clear` ได้เช่นกัน

หน้าแรกให้เลือก ลูกค้า / ครัว / ผู้ดูแลร้าน ทุกหน้ามีปุ่มย้อนกลับของ Expo Router ไม่ต้องแก้ import ใน App.js เพื่อเปลี่ยนหน้าทดสอบอีกแล้ว

## โครงสร้าง

- `src/app/`: routes และ SQLiteProvider จุดเดียว
- `src/screens/`: หน้าลูกค้า ครัว และผู้ดูแล
- `src/components/`: CommonCp, CustomerCp, KitchenCp, AdminCp และส่วน navigation ที่ใช้ร่วมกัน
- `src/db/`: SQL ทั้งหมด การอ่านข้อมูล และธุรกรรมการเขียน
- `src/styles/`: theme และ styles ส่วนกลาง
- `src/context/CartContext.js`: ตะกร้าที่กำลังจัดก่อนส่ง แยกตามบิล
- `tests/restaurantFlows.test.cjs`: ทดสอบด้วย SQLite จริงในฐานข้อมูลชั่วคราว

ฐานข้อมูลหลักชื่อ `restaurant-order-01418342.db` ข้อมูลที่ส่งแล้วอยู่ถาวรใน SQLite ตะกร้าที่ **ยังไม่ส่ง** อยู่ในหน่วยความจำ และจะหายเมื่อปิดแอปจนสุด

## ทดลองใช้งาน

1. ลูกค้า → เลือกโต๊ะ → เปิดบิล → เลือกเมนู → ตะกร้า → ปรับจำนวนและหมายเหตุแยกแต่ละเมนู → ส่งออเดอร์
2. เปิดเมนูอีกครั้งเพื่อสั่งรอบที่ 2 และ 3; ดูสถานะและบิลรวมทุกรอบ
3. กลับหน้าแรก → ครัว → เปลี่ยนแต่ละรายการ รอทำ → กำลังทำ → เสิร์ฟแล้ว
4. ผู้ดูแล → จัดการโต๊ะ → เลือกโต๊ะ → ดูบิล → เลือกเงินสด/QR → ยืนยันรับชำระและปิดบิล
5. เปิดบิลใหม่บนโต๊ะเดิมได้; ดูบิลเก่าผ่านประวัติบิลโดยเลือกวันที่
6. แก้ราคาเมนู แล้วดูว่าบิลเก่ายังคงราคาเดิม
7. ทดลองย้ายบิลไปโต๊ะว่าง และดูว่ารอบ/รายการอาหารยังครบ
8. ตรวจรายงานตามช่วงวันที่และอันดับเมนูขายดี
9. ล้างรายการขายผ่านหน้า Reset: พิมพ์ `RESET` และยืนยัน ลบเฉพาะบิล/ออเดอร์/ชำระเงิน/ย้ายโต๊ะ เก็บ master data และราคาปัจจุบันไว้

แอปใส่โต๊ะ 15 โต๊ะ หมวดอาหาร 4 หมวด และเมนู 25 รายการเมื่อใช้ฐานข้อมูลนี้ครั้งแรก ไม่ใส่ข้อมูลขายตัวอย่างอัตโนมัติ และไม่ใส่ข้อมูลตั้งต้นซ้ำหลัง reset

## ตรวจสอบ

```bash
npm run lint
npm run typecheck
npm test
npx expo install --check
```

Lint/TypeScript ตรวจ JavaScript จริงด้วย `checkJs` Tests ใช้ SQL ของแอปกับ SQLite ในหน่วยความจำ/ไฟล์ชั่วคราว ไม่ล้างฐานข้อมูลของผู้ใช้

รายงานการเทียบเงื่อนไขอยู่ใน `docs/assignment-checklist.md` และหลักฐานฐานข้อมูล/ดัชนีอยู่ใน `docs/database-notes.md`

## ไลบรารีเพิ่มเติม

Expo Router, expo-linking, expo-constants, expo-status-bar, expo-asset, react-native-safe-area-context, react-native-screens, react-native-reanimated, react-native-worklets ใช้เวอร์ชันที่ Expo ติดตั้งให้สำหรับ SDK 57; react-dom/react-native-web สำหรับ dependencies ฝั่งเว็บ ไม่มี ORM หรือ AsyncStorage เก็บข้อมูลหลัก

ตรวจจริงบน iOS Expo Go; Android ตรวจ bundle และฐานข้อมูล แต่ยังต้องทดสอบการแตะบนอุปกรณ์ Android ก่อนส่ง เว็บไม่ใช่เป้าหมายการส่งงาน และ expo-sqlite บนเว็บยังต้องตั้งค่า WASM/headers เพิ่มหากจะใช้งาน
