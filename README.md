## วิธีติดตั้งและรัน

1. แตกไฟล์งาน แล้วเปิดโฟลเดอร์ Restaurant ที่มีไฟล์ package.json
2. ติดตั้ง Node.js 24 และ npm ถ้ายังไม่มี
3. เปิด Terminal ในโฟลเดอร์งาน แล้วติดตั้งแพ็กเกจ

```bash
npm install
```

4. ถ้าใช้ Android ให้เปิด Android Emulator หรือเชื่อมอุปกรณ์ Android ที่ตั้งค่าไว้ แล้วรัน

```bash
npm run android
```

ถ้าใช้ iOS ให้เปิด iOS Simulator บน Mac แล้วรัน

```bash
npm run ios
```

ถ้าใช้มือถือผ่าน Expo Go ให้ใช้รุ่นที่รองรับ SDK 57 แล้วสแกน QR ที่แสดงใน Terminal มือถือกับคอมพิวเตอร์ควรอยู่ในเครือข่ายเดียวกัน

5. เมื่อแอปเปิด เลือกลูกค้า ครัว หรือผู้ดูแลร้านที่หน้าแรก

เปิดครั้งแรกจะมีโต๊ะ 15 โต๊ะ และเมนู 4 หมวด รวม 25 รายการให้ ไม่ต้องกรอกเอง

## ไลบรารีที่เพิ่มจากที่เรียน

- expo-asset เป็นแพ็กเกจจัดการไฟล์ภาพที่ติดตั้งไว้ แต่ตอนนี้โค้ดแอปไม่ได้เรียกใช้โดยตรง
- react-dom และ react-native-web ใช้รองรับเว็บ แต่งานนี้เน้นมือถือ
- expo-linking, expo-constants, react-native-reanimated และ react-native-worklets ติดตั้งไว้ตอนทำระบบเดิม ตอนนี้โค้ดแอปไม่ได้เรียกใช้โดยตรง
- eslint และ eslint-config-expo ใช้ตรวจโค้ดด้วย npm run lint

expo-sqlite, expo-status-bar, react-native-safe-area-context และ react-native-screens มีในตัวอย่าง RegisterBasic ที่เรียนแล้ว ไม่ได้ใช้ ORM หรือ AsyncStorage เก็บข้อมูลหลัก

## สิ่งที่ทำแล้วและส่วนที่ยังไม่ได้ทำ

ทำแล้ว

- เลือกโต๊ะ เปิดบิลใหม่ หรือสั่งต่อในบิลเดิม
- ดูเมนูตามหมวด เพิ่มหรือลดจำนวน และใส่หมายเหตุ
- ตรวจตะกร้าก่อนส่ง และสั่งเพิ่มหลายรอบในบิลเดียวกัน
- ดูอาหารแต่ละรอบ สถานะ และยอดรวม
- ครัวดูรายการตามเวลาสั่ง และเปลี่ยนเป็นรอทำ กำลังทำ หรือเสิร์ฟแล้ว
- ผู้ดูแลแก้ราคา เปิดหรือปิดขายเมนู ย้ายโต๊ะ รับเงิน และปิดบิล
- เก็บราคาตอนสั่ง บิลเก่าจึงไม่เปลี่ยนตามราคาใหม่
- ดูประวัติบิลตามวันที่ ยอดขายแยกหมวด และเมนูขายดี 10 อันดับตามช่วงวันที่
- ล้างรายการขายได้ โดยโต๊ะ เมนู และราคายังอยู่

ส่วนที่ยังไม่ได้ทำ

- ค้นหาเมนู ยกเลิกอาหารพร้อมบันทึกเวลา และเพิ่มเมนูใหม่ผ่านแอป
- แยกบิล ตั้งราคาล่วงหน้า ออกใบเสร็จเป็นไฟล์ ส่วนลด ภาษี ค่าบริการ และตัวเลือกอาหารที่เพิ่มราคา
- QR ยังไม่ได้เชื่อมธนาคาร ใช้บันทึกว่าเลือกจ่ายแบบไหน

ระดับ ข ที่ทำครบคือ ข1 รายงานแยกหมวด ข4 ย้ายโต๊ะ และ ข6 เมนูขายดี 10 อันดับ ส่วน ข5 ทำได้เฉพาะแก้ราคาและเปิดหรือปิดขาย ยังเพิ่มเมนูใหม่ไม่ได้ จึงไม่ได้ระบุว่าทำครบทั้งข้อ

ราคาใช้บาทจำนวนเต็ม ไม่รองรับเศษสตางค์ ข้อมูลที่ส่งแล้วเก็บใน SQLite ส่วนตะกร้าที่ยังไม่ส่งจะหายเมื่อปิดแอป แต่ละเครื่องมีข้อมูลของตัวเอง ตามโจทย์ที่ยังไม่ต้องเชื่อมหลายเครื่อง

ตรวจโค้ดด้วย npm run lint และสร้าง bundle ของ iOS กับ Android ผ่านแล้ว ทดสอบฟังก์ชันฐานข้อมูลกับ SQLite ผ่าน 11 เรื่อง รวมการสั่งสามรอบ การย้อนกลับเมื่อบันทึกไม่สำเร็จ ราคาบิลเก่า ย้ายโต๊ะ ปิดบิล รายงาน และล้างข้อมูล เคยลองเปิดและเปลี่ยนหน้าบน iOS Simulator แต่ยังต้องลองใช้งานบนอุปกรณ์ Android ก่อนส่ง

## เตรียมไฟล์ส่งงาน

ใช้คำสั่งส่งงานล่าสุดเป็นหลัก โดยส่งทั้งหมด 6 อย่าง

1. Group_04_RestaurantOrder.zip รวมโค้ดทั้งโปรเจกต์ ไม่ใส่ node_modules และเก็บ .git ไว้เพื่อให้ตรวจงานของสมาชิก แนบลิงก์ GitHub ด้วย และตรวจว่าไฟล์บน GitHub เป็นรุ่นล่าสุด
2. README.docx วางในโฟลเดอร์หลัก มีสมาชิกและหน้าที่ ลิงก์ YouTube ลิงก์ GitHub วิธีรัน ไลบรารีเพิ่มเติม และส่วนที่ทำแล้วกับยังไม่ได้ทำ ส่วน README.md เก็บไว้ให้อ่านบน GitHub
3. schema.sql วางในโฟลเดอร์หลัก มีตาราง ดัชนี และข้อมูลตั้งต้น ทดสอบรันบน SQLite ว่างและรันซ้ำแล้ว ไม่มีข้อผิดพลาดหรือข้อมูลตั้งต้นเพิ่มซ้ำ
4. Group_04_Report.pdf วางในโฟลเดอร์หลักและแนบใน Classroom เป็น A4 มีหน้าปก 1 หน้าและเนื้อหา 6 หน้า ครบ 10 หัวข้อตามลำดับ ได้แก่ แผนผังตาราง เหตุผลการแยกตาราง ราคาบิลเก่า หลายรอบการสั่ง SQL 3 คำสั่ง ดัชนีและ EXPLAIN QUERY PLAN Transaction ปัญหา 3 เรื่อง การแบ่งงาน และสิ่งที่จะทำต่อ 3 ข้อ
5. ลิงก์ YouTube ใส่ใน README.docx และช่องส่งงาน Classroom คลิปต้องยาว 8–10 นาที และทุกคนพูดอธิบายโค้ดของตัวเองพร้อมเปิดโค้ดจริง
6. แบบประเมินเพื่อน สมาชิกกรอกคนละ 1 ฉบับ ใช้แบบฟอร์มที่อาจารย์แนบ แล้วส่งแยกในช่องของตัวเอง

ไฟล์ README.docx, schema.sql และ Group_04_Report.pdf มีแล้ว ZIP จะจัดเป็น Group_04_RestaurantOrder.zip หลังบันทึกงานล่าสุด โดยไม่ใส่ node_modules และเก็บ .git ส่วนแบบประเมินเพื่อนสมาชิกยังต้องจัดเตรียมและส่งเอง สัดส่วนงานในรายงานยังเป็นร่าง 40/20/20/20 ให้สมาชิกตรวจและตกลงกันก่อนส่ง ต้องตรวจด้วยว่าทุกคนมีหลักฐานเขียน SQL อย่างน้อยคนละ 3 คำสั่ง จำนวน commit อย่างเดียวไม่ได้ยืนยันเรื่องนี้

## ลองใช้งานก่อนส่ง

1. เปิดแอปครั้งแรก ตรวจโต๊ะ 15 โต๊ะ เมนู 4 หมวด รวม 25 รายการ แล้วเปิดใหม่เพื่อตรวจว่าข้อมูลไม่ซ้ำ
2. สั่งอาหาร 3 รอบในบิลเดียว ใส่หมายเหตุ และเทียบยอดกับที่คำนวณเอง
3. เปิดครัว ดูโต๊ะ รอบ และหมายเหตุ แล้วเปลี่ยนสถานะอาหารจนครบ
4. รับเงินและปิดบิล เปิดบิลใหม่ที่โต๊ะเดิม และเปิดดูบิลเก่าในประวัติ
5. เปลี่ยนราคาเมนู แล้วตรวจว่าราคาบิลเก่ายังเท่าเดิม
6. ปิดแอปจนสุดแล้วเปิดใหม่ ตรวจว่าบิลและออเดอร์ที่ส่งแล้วอยู่ครบ
7. ย้ายโต๊ะ ตรวจว่ารายการไม่หาย แล้วลองรายงานแยกหมวดและเมนูขายดี
8. ล้างรายการขาย แล้วตรวจว่าโต๊ะ เมนู และราคายังอยู่ พร้อมเปิดบิลใหม่ได้
9. รัน npm run lint และลองติดตั้งจากไฟล์ ZIP ในโฟลเดอร์ใหม่ตามขั้นตอนด้านบน

รายการนี้เป็นขั้นตอนที่ต้องลองก่อนส่ง ไม่ได้หมายความว่าทดสอบทุกข้อบนทุกอุปกรณ์แล้ว
